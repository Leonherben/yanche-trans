# 言蹊翻译 (YanXi Trans)

<p align="left">
  <b>简体中文</b> | <a href="README_EN.md">English</a>
</p>

轻量、极速的跨平台桌面划词翻译工具，支持 Linux (X11) 与 Windows。

名称取自“桃李不言，下自成蹊”。默认内置免费微软翻译（无需注册任何账号或申请 API 密钥，开箱即用），同时支持接入 DeepSeek、OpenAI、智谱 GLM、本地 Ollama 等大模型。悬浮窗采用无焦点置顶设计，划词查词时不会抢占键盘输入焦点，不影响写代码、敲终端命令或日常打字。

---

## 主要功能

- **免配置开箱即用**：默认内置微软翻译服务，下载即可直接使用，无需任何前置 API 配置。
- **聚合多翻译源**：支持在悬浮窗左上角下拉菜单秒级切换翻译引擎，包括微软翻译、DeepSeek、OpenAI、智谱 GLM 与本地 Ollama（Qwen 等）。
- **无焦点悬浮窗**：翻译气泡弹出时绝不抢占键盘焦点，正在进行的文本输入与光标位置不中断。
- **系统原生字体适配**：Windows 下自适应现代微软雅黑（Microsoft YaHei UI），Linux 下自适应 Noto Sans CJK，全界面温润清晰。
- **单实例运行保护**：内置跨平台本地进程锁，重复点击图标或命令自动呼出已有实例，杜绝进程泛滥与快捷键冲突。
- **灵活取词方式**：
  - **快捷键取词**：选中文本后按下 `Alt + D` 即可翻译，底层针对 Windows 菜单栏失焦与修饰键释放进行专项优化，支持在配置文件中设置多个备用快捷键（如 `Alt + Q`）。
  - **鼠标侧键取词**：支持鼠标前后侧键一键触发划词翻译。
  - **明确的取词模式**：在浮窗顶部、托盘或设置中选择“快捷键查词”“划选即翻译”“伴随阅读”。伴随阅读仅在浮窗打开时自动翻译；快捷键和已启用的鼠标侧键仍可主动取词。
  - **手动查词框**：未选词时按下快捷键，或双击系统托盘图标，均可呼出输入框手动查词。
- **悬浮窗实用特性**：
  - **翻译方向就地切换**：顶部显示源语言与目标语言，点击即可切换。浮窗和托盘切换引擎或语言后自动重译当前原文；浮窗已收起时只更新配置。
  - **引擎配置状态**：引擎菜单使用易读名称，标明免配置、本地服务或密钥配置状态；未配置密钥时直接打开对应服务设置。
  - **失败恢复**：翻译失败后可重试或打开当前服务设置，错误提示不会作为译文复制。
  - **输入翻译开关**：在“设置 → 外观与交互”选择输入后自动翻译，或关闭后用回车 / 翻译按钮提交。修改原文后清除旧译文并提示待重译。
  - **固定位置 (Pin)**：可将悬浮窗固定在屏幕任意坐标，后续查词直接在固定位置显示。
  - **纯译文模式**：支持隐藏原文仅展示译文，视觉更清爽。
  - **统计与耗时**：实时展示单词数、字符数以及翻译请求的毫秒耗时。
  - **透明度调节**：支持在托盘中按百分比调节窗口透明度（40% ~ 100%）。
  - **多主题适配**：提供亮色（Light）、暗黑（Dark）与毛玻璃（Glass）三套现代主题。
  - **快捷收起**：按下 `Esc` 键或点击悬浮窗外部空白区域即可收起窗口。
  - **收起与旧结果隔离**：右上角 ✕ 表示收起，程序仍在托盘运行；收起后旧请求不会重新弹窗。连续查询只展示最新请求，清空或修改原文也会使旧结果失效。
- **可视化设置中心**：托盘与悬浮窗内置图形设置窗口，可直接在界面中输入与管理各服务商 API Key（带防窥密码切换）、自定义模型参数、一键测试 API 连通性、配置快捷键与外观，完全无需接触命令行。
- **在线版本更新检测**：设置与托盘菜单内置【软件更新与关于】，可检测 GitHub 发布的最新版本、预览更新日志并一键下载更新。
- **离线本地缓存**：内置 SQLite 缓存，相同词句 0ms 秒级响应，节省大模型 API 资费与网络开销。
- **终端命令行工具**：提供 `yanxi-cli`，支持在终端中快速查词与交互式翻译。

## 常用操作与快捷键

| 操作 / 快捷键 | 功能 | 说明 |
| :--- | :--- | :--- |
| `Alt + D` | 划词翻译 / 展开收起浮窗 | 选中文本时极速翻译；未选词时一键展开/收起悬浮窗 (Toggle) |
| 鼠标划选松开 | 伴随阅读划词翻译 | 默认开启伴随阅读模式：仅在悬浮窗处于打开状态时划词自动翻译，就地刷新不跳跃；关闭悬浮窗时完全静默不打扰日常工作 |
| 鼠标前后侧键 | 划词翻译 | 支持大部分带有侧键的鼠标一键取词 |
| 双击托盘图标 | 打开查词框 | 快速呼出悬浮窗并聚焦手动查词框 |
| 托盘右键 / 浮窗更多菜单 | ⚙ 设置 | 打开图形配置中心，可视化修改服务商 API Key、模型、快捷键、开机启动与外观 |
| `Esc` / 浮窗右上角 `✕` | 收起翻译悬浮窗 | 伴随阅读结束时一键关闭，恢复静默模式 |
| `Ctrl + Alt + Escape` | 紧急退出程序 | 后台守护进程异常时的全局强制退出键 |

## 服务配置与 API Key

默认无需修改任何配置即可使用微软翻译。若需使用 DeepSeek、OpenAI、智谱 GLM 或本地 Ollama 等模型，可通过以下方式配置：

### 方式一：图形界面配置（推荐）
点击右下角系统托盘菜单中的 **⚙ 设置**（或悬浮窗左上角引擎下拉菜单中的 **⚙ 管理服务与 API Key**），即可直接填入 API Key、修改模型名称与 Base URL，并可点击 **“⚡ 测试当前服务连通性”** 即时验证。

### 方式二：命令行或配置文件
配置文件路径：
- **Linux**：`~/.config/yanxi/config.json`
- **Windows**：`%APPDATA%/yanxi/config.json`

亦可通过终端命令快速设定：

```bash
# 配置 DeepSeek API Key
yanxi-cli --set-key deepseek sk-your-deepseek-api-key

# 配置 OpenAI API Key
yanxi-cli --set-key openai sk-your-openai-api-key

# 配置 智谱 GLM API Key
yanxi-cli --set-key zhipu your-zhipu-api-key

# 查看所有已配置的提供商状态
yanxi-cli --list-providers
```

## 命令行用法 (yanxi-cli)

```bash
# 单次翻译文本
yanxi-cli "Standing on the shoulders of giants."

# 指定源语言与目标语言（如翻译为日语）
yanxi-cli "Good morning!" -t ja

# 指定使用的翻译引擎
yanxi-cli "Hello world" -p deepseek

# 进入终端交互式翻译模式
yanxi-cli -i
```

## 源码运行与开发

本项目推荐使用 [uv](https://github.com/astral-sh/uv) 管理 Python 虚拟环境与依赖（Python 3.12+）：

```bash
# 1. Linux 前置依赖 (Linux 专属，用于 X11 取词)
sudo apt update && sudo apt install -y xsel libxcb-cursor0

# 2. 安装 Python 依赖
uv sync

# 3. 运行 GUI 划词主程序
uv run yanxi

# 4. 运行命令行查词工具
uv run yanxi-cli "Hello world"

# 5. 执行单元测试
uv run pytest

# 6. 本地打包构建独立发布包
uv run python scripts/build.py
```
