# 言蹊翻译 v0.1.9 更新说明

版本号统一为 `0.1.9`，已合并至 `main`。

## 本轮改动

- **极简单行顶栏交互**：
  - 顶栏控件整合为单行紧凑布局（`[翻译源] [语言方向] [取词模式] [固定] [设置] [关闭]`），大幅提升纵向阅读与展示空间。
  - 清理多余装饰性符号：去除下拉三角（`▾`）、对勾符号（`✔`）、齿轮符号等冗余图标，界面更加纯粹克制。
- **全新圆角灰阶统一视觉体系**：
  - 深色、浅色与毛玻璃全主题采用低饱和度灰阶设计，去除高反差着色。
  - 统一大圆角（按钮、输入框、胶囊均统一 8px/6px 圆角），视觉风格柔和内敛。
- **更直观的模式与功能命名**：
  - 取词模式重命名为：“快捷键翻译”、“划选即翻译”、“划词翻译（仅开窗）”。
  - 托盘“输入查词...”统一优化为“打开翻译窗”。
- **全面优化的推荐默认配置**：
  - **默认快捷键**：调整为 `<alt>+q`，有效避开 Windows 系统、Chrome 及办公软件的冲突热键。
  - **默认固定窗口**：启动即固定位置，避免查词窗口跳跃。
  - **开机显示浮窗**：首次或启动时默认展现浮窗，便于立即使用。
  - **更合理的交互节奏**：手动输入翻译默认改由 Enter 触发（Shift+Enter 换行）；关闭鼠标侧键查词避免前进后退误触；自动收起间隔统一为 10 秒；默认不透明度为 100%。

## 下载与使用

1. 从 GitHub Releases 下载 `yanxi-v0.1.9-windows-x64.zip`（Windows 免安装绿色版）或 `yanxi-v0.1.9-linux-x86_64.tar.gz`（Linux 版）。
2. 解压到任意无中文空格的本地目录，保留 `yanxi.exe` 与 `_internal` 依赖文件夹。
3. 直接双击 `yanxi.exe` 即可使用，无需安装 Python 环境。
4. 用户的自定义配置存储于系统安全目录（Windows: `%APPDATA%\yanxi\config.json`），更新版本不会丢失配置与本地缓存。
