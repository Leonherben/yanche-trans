# 言蹊翻译 v0.2.1 更新说明

版本号统一为 `0.2.1`，已发布至 GitHub 并合并到 `main` 分支。

## 本次更新重点修复与优化

本版本针对 `v0.2.0` 用户反馈与打包细节进行了专项优化与体验修复：

1. **动态系统音频输出设备同步（修复插拔耳机声音未切换）**：
   - 针对 Qt 6 音频设备绑定机制进行重构，接入 `QMediaDevices.audioOutputsChanged` 信号监听；
   - 每次播放音频前动态校验并同步系统默认音频输出设备，解决插拔 3.5mm 有线耳机或连接蓝牙耳机时，音频未能及时切换到耳机、仍然在扬声器外放的问题。

2. **修复独立运行包缺失多媒体依赖导致的闪退问题**：
   - 修复 `yanxi.spec` 打包配置中多媒体模块排除规则导致的依赖遗漏；
   - 补全 `PySide6.QtMultimedia`、`yanxi.core.tts` 与 `yanxi.adapters.gui.audio_player` 的隐式导入与运行时依赖，确保解压后即可稳定双击启动。

3. **发音播放增益与听感校准**：
   - 将底层音频播放默认软件增益校准为 `0.85`，有效解决满幅规范化（0 dBFS）原声音频在部分设备上播放声音偏大、突兀或微失真的问题，发音体验更加柔和舒适。

## v0.2.x 核心特性回顾

- **英美双排真人发音 (TTS)**：
  - 原生支持 **英式发音 (UK)** 与 **美式发音 (US)**，在原文与译文底栏提供并排双按钮：`[英 🔊]` 与 `[美 🔊]`。
  - **单词与短语真人原声**：地道母语真人发音接口，发音清晰地道。
  - **长句流畅朗读**：智能平滑调度长文本发音通道，保证完整长句稳定发声。
  - **多线程异步与防串音**：网络拉取在独立后台线程执行，界面绝不卡顿；提供播放序列锁防爆音防串音。
  - **0ms 秒级磁盘哈希缓存**：音频安全缓存至本地，相同词句仅需请求一次，二次发音零延迟即时播放。

- **语言智能感知（纯净界面无杂讯）**：
  - 智能感知内容语种：仅在卡片文本包含英文字符时才显示 `[英 🔊]` `[美 🔊]` 按钮；
  - 消除中文发音违和感：英译中时译文卡片自动隐藏发音；中译英时译文卡片智能显示发音；纯中文划词两侧均自动隐藏发音。

## 下载与使用

1. 从 GitHub Releases 下载预编译独立运行包：
   - Windows: `yanxi-v0.2.1-windows-x64.zip`（免安装绿色版）
   - Linux: `yanxi-v0.2.1-linux-x86_64.tar.gz`（Linux 便携版）
2. 解压到本地任意目录，直接双击 `yanxi.exe` 或运行 `启动言蹊翻译.bat` 即可运行，完全免配置、无需安装 Python 环境。
3. 用户的已有自定义配置与翻译缓存永久保留，更新版本无缝兼容。
