# 言蹊翻译 v0.2.0 更新说明

版本号统一为 `0.2.0`，已发布至 GitHub 并合并到 `main` 分支。

## 本轮重大新增特性

- **全新英美双排真人发音模块 (TTS)**：
  - 原生支持 **英式发音 (UK)** 与 **美式发音 (US)**，在原文与译文底栏提供并排双按钮：`[英 🔊]` 与 `[美 🔊]`。
  - **单词与短语原生真人发音**：单词查词调用地道母语真人发音接口，发音清晰地道，满足日常查词与口语辨音需求。
  - **长句流畅朗读与智能回退**：对完整长句自动平滑调度长文本发音通道，保证任意长度段落均可稳定发声。
  - **多线程非阻塞安全播放**：基于 PySide6 `QMediaPlayer` 异步事件驱动，网络拉取在独立后台线程执行，绝不卡顿悬浮窗界面；提供序列锁防爆音防串音。
  - **0ms 秒级磁盘哈希缓存**：音频自动缓存至本地安全目录（`%APPDATA%\yanxi\audio_cache` 或 `~/.config/yanxi/audio_cache`），相同词句仅需请求一次，二次发音零延迟即时播放。

- **内容语言智能感知（无视觉杂讯）**：
  - **智能识别内容语种**：仅在卡片文本包含英文字符时才显示 `[英 🔊]` `[美 🔊]` 按钮；
  - **彻底消除中文发音违和感**：
    - **英译中场景**：原文卡片（英文）显示发音，译文卡片（中文）**自动隐藏**发音按钮；
    - **中译英场景**：原文卡片（中文）自动隐藏，译文卡片（英文）**智能显示**发音按钮，便于确认译文读音；
    - **纯中文划词**：两侧均不显示发音，界面保持纯净克制。

## 下载与使用

1. 从 GitHub Releases 下载预编译独立运行包：
   - Windows: `yanxi-v0.2.0-windows-x64.zip`（免安装绿色版）
   - Linux: `yanxi-v0.2.0-linux-x86_64.tar.gz`（Linux 便携版）
2. 解压到本地任意目录，直接双击 `yanxi.exe` 即可运行，完全免配置、无需安装 Python 环境。
3. 用户的已有自定义配置与翻译缓存永久保留，更新版本无缝兼容。
