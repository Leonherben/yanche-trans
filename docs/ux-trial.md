# 言蹊翻译交互改进试用版

本地构建标识：`ux-20261002`。基于上游 v0.1.7，不改变上游版本号。

## 本轮改动

- “偏好设置”统一改为“设置”。
- 取词模式统一为“快捷键查词”“划选即翻译”“伴随阅读”，暂停状态不会因切换模式丢失。
- 右上角关闭按钮明确表示收起；收起、修改原文或开始新查询后，旧请求不能重新弹窗或覆盖结果。
- 浮窗显示翻译方向，浮窗和托盘切换引擎或语言后重译当前编辑原文；隐藏或空输入不触发重译。
- 引擎使用易读名称，显示免配置、本地服务或密钥配置状态。未配置密钥时直接打开该服务的设置。
- 翻译失败可重试、打开设置；错误提示不会作为译文复制。
- “设置 → 外观与交互”增加输入后自动翻译开关，默认保留原有自动翻译行为。
- 修改原文后清除旧译文和复制来源，提示待重新翻译；保存设置使在途请求失效时也会更新提示。
- 修复 Windows SQLite 文件占用、单实例唤醒丢失，以及旧控制台编码导致的日志异常。

## 使用

1. 解压完整压缩包，保留 `yanxi.exe` 与 `_internal` 文件夹的相对位置。
2. 若原版正在运行，先从托盘选择“退出”，再双击试用包中的 `yanxi.exe`。
3. 程序沿用用户原有配置和缓存；新设置项在旧配置中缺失时使用兼容默认值。
4. 此包独立于原安装目录，可退出试用版后重新打开原版。

该版本的配置状态只反映本地配置，不保证密钥有效或网络连通。收起会丢弃旧请求的
界面结果；已经发出的同步网络请求可能继续完成。

## 验证与构建

全量 143 项自动化测试通过，包含可控的乱序翻译响应、临时配置、模拟剪贴板以及
真实子进程的单实例唤醒。浮窗 360 / 450 像素宽度、引擎菜单、错误操作区和设置
页面经过离屏渲染检查。

项目使用独立 uv 环境。构建命令：

```powershell
uv run --group dev python scripts/build.py --label ux-20261002
```

Windows 构建时优先从系统目录解析 Qt 系统依赖，避免其他工具的同名 ICU DLL
被错误打入程序。构建标识记录在包内 `BUILD_INFO.json`。
